# 160-FTL-V2

## 项目简介
本项目是专为《我的世界》（Minecraft）设计的 **160-ftl-v2 型珍珠炮** 一键计算工作流程序。

该程序旨在简化传统珍珠炮繁琐的手动计算流程，通过输入目标坐标或预设参数，自动计算出该型号珍珠炮所需的参数，帮助玩家快速完成炮体部署与精准打击。

## 功能特性
- 🧮 **一键智能计算**：输入目标坐标或水平/垂直距离，自动解算 160-ftl-v2 炮体模型下的最优发射参数。
- ⚙️ **工作流自动化**：整合角度计算 → 延时生成 → 指令输出全流程，减少人工查表与试射成本。
- 📐 **支持**：基准坐标选择炮的坐标，通过自己计算的tick来计算速度通过终点坐标来获得最终的周围几组数据，方便传送到那一片。
- 📋 **结果可视化**：通过翻找计算的过程来获得。
