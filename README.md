# 160-FTL-V2

## 项目简介
本项目是专为《我的世界》（Minecraft）设计的 **160-ftl-v2 型珍珠炮** 一键计算工作流程序。

该程序旨在简化传统珍珠炮繁琐的手动计算流程，通过输入目标坐标或预设参数，自动计算出该型号珍珠炮所需的精确发射角度（俯仰角/偏航角）、TNT 推进延时序列以及末影珍珠落点修正值，帮助玩家快速完成炮体部署与精准打击。

## 功能特性
- 🧮 **一键智能计算**：输入目标坐标或水平/垂直距离，自动解算 160-ftl-v2 炮体模型下的最优发射参数。
- ⚙️ **工作流自动化**：整合角度计算 → 延时生成 → 指令输出全流程，减少人工查表与试射成本。
- 📐 **多模式支持**：（如有）支持定点打击、最大射程覆盖等不同战术模式。
- 📋 **结果可视化**：清晰输出俯仰角、偏航角、各推进单元延迟刻数（gt）及预估飞行时间。
